# Hong Kong Fishing

16:9 first-person fishing mini-game with four configurable fishing areas, weighted fish species, timing-based reeling, score rewards, persistent local catch bag, and a Firebase-powered admin CMS.

- Game: `index.html`
- Admin: `admin.html`
- Firebase project: `yes-card-gacha-rgb`
- Firestore document: `miniGames/hongKongFishing`
