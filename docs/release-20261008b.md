# Android 1.2.14（版本代碼 20）／網站更新

- 主畫面及遊戲設定新增「儲存／讀取進度」，提供三格獨立手動紀錄。
- 每格保存魚獲、圖鑑、金幣、魚餌、愛心、物件、證書、解鎖及所在區域；原有自動儲存繼續運作。
- 儲存、覆蓋和讀取都有確認；讀取完整還原該次進度，不會把較新雲端事件重新加回。讀取後的進度成為目前帳戶的新進度。
- 手動紀錄只保存在此裝置／此瀏覽器，訪客與登入帳戶分開。清除應用程式資料或解除安裝會移除紀錄，並非跨裝置雲端備份。
- Android「重新開始」保留三格手動紀錄，重設目前自動進度。
- 海鮮檔售罄提示改為深色字、淺色底。
- 包含 1.2.13 核對後的魚類圖片。

驗證：網站及 Android 內置內容的三格獨立存檔、取消、完整還原、重開持續保存、儲存空間不足保護、帳戶隔離及售罄文字顏色；雲端不同進度分支不會混合，同一分支及舊有紀錄仍正常合併；魚圖與難度／地區回歸測試。
