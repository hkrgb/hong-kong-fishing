# Generated fish illustration assets

Built-in ImageGen, 138 completed species illustrations, one image per named species. Existing 12 artworks are retained, giving all 150 catalogue entries artwork. Each generated species has a JSON prompt record; manifest.json is the authoritative final selection and visual-review record, including revised images. Individual generation records retain their original pre-review status. These are AI-created game illustrations, not photographs or authoritative identification plates; exact anatomy and markings have not been expert-verified.

PNG masters are retained locally; WebP delivery files preserve the full composition while reducing transfer size. No third-party photographs are copied. The gallery loads only visible images rather than preloading all species in a region. Existing catches with missing artwork resolve the current catalogue image by stable fish ID.
