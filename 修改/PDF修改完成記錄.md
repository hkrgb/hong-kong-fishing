# UI 修改記錄

依據 `修改資料/ui.pdf`（18 頁）及提供的五張配圖修改。原始 PDF 和配圖保持不變，正式使用的配圖副本位於 `sport/assets/island-ui/`。

- 首頁：離島旅程圖片標題、版本 ver 1.0，保留登入、讀取、全屏幕和備份。
- 旅程目錄：早、午、晚離島背景，前往釣魚、前往店舖、小遊戲三個縮圖入口。
- 釣區、商舖及簡介：白色半透明面板、藍字標題、圖片卡片、返回按鈕；簡介採左圖右文。
- 垂釣：左上顯示釣點名稱、左下返回目錄。長洲本地轉釣點不播船片；往返外區播放船片，保留船費規則。
- 魚餌、購物、圖鑑及魚獲詳情套用淺色樣式；右上資訊按鈕改為「魚類簡介」。
- 手帳：使用提供的書本配圖，四個入口為全屏幕、遊戲／故事起源、免責聲明、聯絡我們；故事網址及電郵依 PDF 設定。
- 平安包打地鼠：釣魚整合版使用工作區內的 `mini-game/peace-bun-whack/`，初／中／高級各獎 $100／$200／$300，三關累積 $600。每關通過即回存，不必全部通關；同一通關重複通知不重複入帳。釣魚模式誤打蛋撻扣一次命中，不扣已取得獎金。獨立／故事版本保留原有計分方式。

## 驗證

瀏覽器實測主入口及 sport 入口、手機 844 × 390 橫向、各主要面板、跨區短片觸發、三關獎金、重複回報、重新載入存檔，無 JavaScript 執行錯誤。自動化金錢帳本測試 8 項通過。

完整既有測試另有一項原有資料問題：`tests/fish-education.test.cjs` 要求所有魚類介紹的 `source` 為 HTTPS 網址，而現有魚類工作表資料有非 HTTPS 的來源描述。本次未修改該簡介資料或放寬該測試。

## 使用與發佈

修改同步到 `output/mini-game/` 對應檔案。此次只修改本機檔案，沒有發佈 GitHub Pages。PDF 所列原網站為 https://hkrgb.github.io/peace-bun-whack/；要讓線上版本具有回存功能，發佈時需同時更新釣魚及平安包兩個遊戲，並保留它們的同層路徑。只發佈釣魚遊戲、仍載入舊版平安包網頁，無法收到新的通關獎金訊息。

單機金錢沿用現有瀏覽器存檔／雲端事件合併機制；不是伺服器驗證的多人競賽金錢。
