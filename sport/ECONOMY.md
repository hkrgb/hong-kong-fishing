# 遊戲金錢與商街

金錢與通關分數分開保存。新舊玩家首次使用此功能均有 $500、10 份基本魚餌；重新載入不重複派發。

## 預設設定

- 基本魚餌 $10：本區任何魚種。
- 高級魚餌 $60：本區同時有已釣過及未釣過魚種時，60% 選未釣過、40% 選已釣過。
- 最高級魚餌 $150：100% 選本區未釣過魚種。
- 若本區全部未釣過，高級魚餌自然只選未釣過魚種；若全部釣過，兩種高級魚餌均不可使用、不扣庫存。
- 機率只指魚種選擇，不保證成功收魚。每次實際拋竿消耗一份，空手收回及斷線不退款。
- 四個釣區依次 $0／$200／$400／$800，一次解鎖，重訪免費。
- 魚獲售價預設每公斤 $50，四捨五入，最低 $10。每尾只能出售一次，仍保留圖鑑、魚獲歷史及獎章。
- 金錢不足以買基本餌且所有魚餌耗盡時，可領取 3 份救急基本餌。

後台可修改魚餌價格、各區解鎖費、預設每公斤售價及個別魚種每公斤售價。第一區固定免費。

## 儲存及相容性

`economyEvents` 與魚獲一起保存至原有本機／Google 雲端存檔，亦透過 `fishingProgress.coastline` 交回主程式。賣魚不刪除 bag，避免出售後重新變成未發現魚種。

每筆交易有唯一 ID 及順序；合併存檔時去重並確定性重播，不把兩份初始金錢相加。同一尾魚或釣区不會重複入帳／收費。離線多裝置同時花費可能產生衝突；合併後餘額不足的交易會被拒絕，而非產生負餘額。此為本機遊戲經濟，並非伺服器防作弊或真實金錢交易系統。未登入的本機資料仍可能因清除網站資料而遺失。

## 美術

使用 imagegen 技能及內置 ImageGen 生成四張素材，位於 `assets/economy/`：釣具店、海鮮檔、三款魚餌組合、海鮮磅與魚籃。WebP 用於遊戲；原始 PNG 保留本機。完整提示詞見該目錄 `manifest.json`。

## 驗證

`node --test tests/economy.test.cjs` 驗證起始金錢、購買、庫存、出售去重、解鎖去重、跨存檔合併、60%／100% 魚種池及救急補給。
